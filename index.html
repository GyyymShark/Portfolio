🔧 실무 트러블슈팅

01. 메인페이지 속도 개선
문제
메인페이지의 FCP · LCP 지표가 사용자 체감 속도를 떨어뜨리는 수준이었음. 무거운 정적 파일(JS / CSS)과 메인 히어로 영역의 CSR 렌더링 방식이 초기 그리기 시점을 지연시키는 주요 원인
시도
① main_fcp.js · main_fcp.css 등 정적 파일 용량 압축으로 다운로드 · 파싱 비용 절감 ② 첫 화면을 좌우하는 메인 히어로 영역을 CSR → SSR로 전환해 의미 있는 콘텐츠를 서버에서 선렌더링
결과
FCP · LCP 지표 개선 · 메인 히어로 영역이 첫 페인트 시점에 즉시 노출되어 초기 체감 속도 향상
배움
"무엇을 줄일까"(정적 자원 용량)와 "언제 그릴까"(렌더링 시점) 두 축을 함께 다룰 때 Core Web Vitals 개선 효과가 가장 크다
